## 2. Merge Conflict & Resolution

### Conflicted File: `packages/coding-agent/package.json`

#### Context
- **Upstream (`stable` @ v0.9.5 / commit `dd760d31` #2140):** Refactored the native binary compilation out of inline package scripts and into dedicated Node scripts:
  ```json
  "build:binary": "node scripts/build-binary.mjs",
  "copy-binary-assets": "node scripts/copy-binary-assets.mjs",
  ```
  `scripts/build-binary.mjs` executes workspace TypeScript compilation directly using `node_modules/.bin/tsgo` across packages, followed by standalone binary bundling with `bun`.
- **Branch commit (`467e5b613`):** Had updated the pre-v0.9.5 inline `build:binary` script from `npm --prefix ...` to `pnpm --prefix ...`.
